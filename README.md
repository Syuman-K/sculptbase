# SculptBase

分割済みの高密度パーツを「**四角面ベース + Multires + 接合部保護マスク**」に変換する Blender アドオンです。
分割後の詳細造形(sculpt フェーズ)を、軽いデータのままマルチレゾリューションで行えるようにします。

対応 Blender: 4.2 以降（拡張機能形式 / 開発・検証は Blender 5.0）。

## 背景

「形状作成 → 分割 → **リトポ → 詳細造形** → 出力」ワークフローの「リトポ→転写」を1クリック化するツールです。
詳細造形を分割後に移すことで:

- スカルプトモードの undo はストローク単位 → オブジェクトモードの全シーンコピー undo による1秒フリーズが起きない
- 重いディテールは「編集中の1パーツのマルチレゾ」に局所化される
- ダボ・分割面はマスクで機械的に保護され、勘合が崩れない

## 接合部の原形保持(v0.2.0〜, 既定 ON)

リメッシュ + Catmull-Clark 転写は近似のため、ダボのような小さく鋭い形状は僅かに崩れます。
v0.2.0 からは接合部(ダボ + 周辺スカート)の面を**リメッシュ前に `<名前>_joint` オブジェクトへ分離**し、
元のジオメトリを**1頂点も変えずに**保持します(ヘッドレステストでダボ角座標の完全一致を検証済み)。
本体側は穴を塞いでからリメッシュ・転写され、`_joint` との境界近傍はマスク保護されます。

詳細造形が終わったら **出力用に統合** ボタンで、Multires をトップレベルで適用した本体と `_joint` を
ブーリアンで統合した出力メッシュを作ります(ベースと `_joint` は `SB_Sculpt` コレクションに
退避されるので再編集も可能)。そのまま PhasePorter で `print_` へ移行してください。

### 出っ張り(ダボ)と窪み(ダボ穴)を作り分ける(v0.4.0〜)

接合部チャンクは**元パッチの向き(パーツ外向き)を保ったまま**蓋で閉じてあるので、
その**符号付き体積の符号がそのまま特徴の種類**になります。

| 符号付き体積 | 特徴 | 統合の演算 |
| --- | --- | --- |
| 正 | 出っ張り（ダボ本体） | 本体に `UNION` して復元 |
| 負 | 窪み（ダボ穴） | 本体から `DIFFERENCE` して掘り直す |

v0.3.0 までは常に `UNION` していたため、**ダボ穴側では「空洞そのもの」を足してしまい穴が埋まる**
不具合がありました（実データで確認: 埋まったセル 6,846/74,088・最深 0.27）。
v0.4.0 ではチャンクを**連結成分ごとに**分解し、成分ごとに演算を選ぶので、
1 つのパーツにダボとダボ穴が混在していても正しく処理されます。

あわせて、蓋がベース表面と同一面に重なってブーリアンが退化する問題を、
**蓋の面を自身の法線方向へ押し出して角柱にする**ことで解消しました。押し出し方向は
必ず「特徴の反対側」（ダボなら本体内部、ダボ穴なら外側の空間）になるため、
**出力表面には一切現れません**。

さらに **穴埋めの強化**（`holes_fill` が扱えないねじれループを扇形で確実に塞ぐ）と
**ソルバーの自動選択**（Manifold → 失敗時 Exact）で、統合の成功率を上げています。

統合後は既定で**接合部の自己検証**が走り、ソース（`SB_Source` の元パーツ）と形状が
食い違っていれば警告します。

> **注意**: v0.3.0 以前で分離した `_joint` には蓋の情報がないため、v0.4.0 の統合は
> 中止して警告を出します。**「スカルプトベースに変換」からやり直してください。**

## パイプライン(パーツごと)

1. **四角リメッシュ** — ベースメッシュを生成。エンジンは自動検出で2種:
   - **QuadWild / Bi-MDF**(推奨): [QRemeshify](https://github.com/ksami/QRemeshify) 拡張がインストールされていれば利用。
     Pietroni et al. ["Reliable Feature-Line Driven Quad-Remeshing"](https://dl.acm.org/doi/10.1145/3450626.3459941) (SIGGRAPH 2021) +
     [Bi-MDF ソルバー](https://github.com/cgg-bern/quadwild-bimdf) (Heistermann et al., SIGGRAPH Asia 2023)。
     シャープ特徴に沿った高品質な四角面。密度等の詳細設定は QRemeshify パネル側に従う。
   - **QuadriFlow**(フォールバック): Blender 組み込み (Huang et al., SGP 2018)。依存なしで動作。
2. **形状転写** — ベースに Multires を付け、レベルごとに
   「Multires 細分化 → 同レベルの Catmull-Clark サブディビ + シュリンクラップ (Target Project) した参照メッシュを生成 → `multires_reshape`」
   を繰り返し、元の高密度形状を各レベルへ焼き込む。検証テストでは寸法誤差 0.1% 未満。
3. **接合部保護** — 他パーツ表面から指定距離内のベース頂点を接合部(分割面・ダボ)として BVH で検出し、
   - スカルプトマスク `= 1.0`(ブラシが動かせない = 実効の保護)
   - 頂点グループ `SB_JointGuard`(可視化・再利用)
   - フェイスセット(スカルプトモードの表示・自動マスク連携)
   の三重で保護する。
4. **ソース退避** — 元の高密度パーツは `SB_Source` コレクションに移し、**ビューレイヤーから除外**
   (依存グラフの評価対象外になるため、残しても重くならない)。結果オブジェクトが元の名前を引き継ぐ。

## 使い方

1. 分割済みパーツを**全部まとめて選択**（接合部検出はパーツ同士の近接で判定するため）。
2. サイドバー（`N`）**SculptBase** タブで設定を確認して **スカルプトベースに変換**。
   変換と統合は**ヘッダーの進捗バー**（レンダリング時と同じもの）とステータス行に
   `[███░░░] 42%  part_A (1/8) — 形状転写 L2/3` のように現在の処理を表示しながら進み、
   **Esc で中断**できます（v0.3.0〜）。
3. スカルプトモードで Multires レベルを上げて詳細造形。マスク済みの接合部は彫れません。
4. 手動リトポしたパーツには **接合部マスクを再検出** だけを使うこともできます（2個以上選択）。

## 設定

- **リメッシュエンジン** — QRemeshify 検出時は QuadWild を選択可能。
- **目標四角面数**（QuadriFlow 時）— ベースの面数（既定 8,000）。
- **Multires レベル** — 既定 2。実効面数は `目標四角面数 × 4^レベル`（8,000 × 4² = 128,000）。
  パネルに最大レベルの面数が表示され、選択パーツ合計が 400 万面を超えると警告アイコンが出ます。
  ここを上げすぎると変換・統合ともメモリと時間を大量に消費します
  （実測: 20,000 面 × レベル3 のパーツ2個で 21 GB 超）。
- **Multires レベル** — 焼き込む段数（既定3）。ビューポート表示はレベル1に設定される。
- **接合部判定距離** — 他パーツ表面からこの距離以内を保護（既定 1mm 相当。シーン単位に依存）。
- **接合部の原形を保持**（既定 ON）— 接合部を `_joint` に分離して元ジオメトリを完全保持。
- **分離マージン** — 分離範囲を判定距離からこの量だけ広げる（既定 3mm 相当）。広いほど出力時のブーリアン統合が確実になるが、スカルプトできない領域が増える。
- **押し出し深さ** — 統合時に接合部チャンクの蓋を押し出す深さ。既定 0（自動＝接合部サイズの 2%）。統合に失敗する・食い違い警告が出る場合はここと分離マージンを広げる。
- **統合後に接合部を検証** — 出力とソースを抜き取り比較し、食い違いが 5% を超えたら警告する（既定 ON）。
- **ソースを退避して残す** — 無効にすると高密度ソースを削除。
